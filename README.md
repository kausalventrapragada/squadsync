# Squad Sync

Production-oriented foundation for the Squad Sync team-building platform.

## Current phase

Phase 1: foundation + landing page.

Included:
- Next.js App Router + TypeScript
- Tailwind CSS 4
- Accessible base button component
- Landing navigation
- Responsive hero
- Product flow section
- AI role-analysis preview
- Reduced-motion support
- Metadata and typed routes

## Run locally

Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```
